# 🔐 Frontend Password Validation Challenge

This project is a **React-based Password Validation App** built as part of the **HENNGE Frontend Engineering Challenge**.

It validates user credentials based on defined security rules and demonstrates real-world frontend validation and API submission using Basic Authentication.

---

## 🚀 Features

- Real-time password validation  
- Clean, responsive UI  
- Built with **React + Vite**  
- Secure submission using **Base64 Basic Auth**  
- Handles Windows (PowerShell) environment setup  

---

## 🛠️ Tech Stack

- React.js  
- JavaScript (ES6+)  
- Vite  
- HTML5 + CSS3  
- REST API  

---

## ▶️ Run Locally

```bash
pnpm install
pnpm run dev

```

App runs at:  
http://localhost:5173


## 📌 Purpose

This project was developed to complete the **HENNGE Frontend Password Validation Challenge**, showcasing:

- Form accessibility best practices  
- Strong password validation logic  
- API integration with authentication  
- Practical debugging and environment setup
